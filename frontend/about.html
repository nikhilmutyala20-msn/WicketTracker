ABOUT WICKET TRACKER

About Wicket Tracker

Wicket Tracker is a cricket video analysis web application designed to help coaches, players, and cricket analysts identify and analyze wicket-taking moments from match videos.

The system takes a cricket video as input and processes it using Computer Vision and AI techniques. It uses YOLOv8 for detecting important objects such as the ball and pitch area.

The detected information can be used to track the ball's movement and identify the area where a dismissal occurs.
